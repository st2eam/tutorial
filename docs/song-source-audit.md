## 《安和桥》

- 唯一参考：[ukuleleba《安和桥》G 调参考谱](https://www.ukuleleba.com/22127.html)。页面可访问，核对日期 2026-09-24。
- 谱头/页面文字已核实：G 调、4/4、约 65 BPM；和弦表 C、D、Em、G；伴奏型 A、B；编配署名莉莉克丝 Leleex。和弦列表不表示小节进行。
- 教学段落：`intro`、`verse`、`chorus`、`bridge`、`outro`。这些是拾艺自制教学音型与段落练习，不是已逐音核对的谱例；各段旋律音高及具体节奏均待对照参考谱图复核。`verse`、`chorus` 在演奏路线中重复引用同一段数据。
- 已修正文案：明确均匀下扫不代表参考谱 A/B；谱卡说明自制音型，休止与延音是教学节奏练习。

## 《成都》

- 唯一参考：[ukuleleba《成都》参考谱](https://www.ukuleleba.com/22137.html)。页面可访问，核对日期 2026-09-24；谱头另以用户提供的截图复核。
- 已核实：C 指法、原调 D、6/8、约 91 BPM；和弦表 C、G、Em、Am、F、Dm；一个伴奏型；女声夹 0 品、男声夹 2 品是参考建议而非强制要求。该谱伴奏含拨弦动作。
- 教学段落：`intro`、`verse-a`、`verse-b`、`chorus`、`bridge`、`outro`。除谱头事实外，站内旋律音高和各段落逐音对应仍待核对；六拍下扫是拾艺入门数拍练习，不是原伴奏。`intro`、主歌和副歌的回归在路线中引用同一段数据。
- 已修正文案：不再把六拍下扫称作原曲伴奏；谱卡明确标注自制音型与未核实旋律。
