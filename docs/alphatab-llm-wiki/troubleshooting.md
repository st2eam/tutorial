# Troubleshooting

| Symptom | Check | Source |
| --- | --- | --- |
| The notation area is empty | Confirm the container has a measurable size, score loading completes, and `error` is observed. Check the score URL and the Vite worker configuration. | [Web configuration](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/getting-started/configuration-web.mdx), [Vite installation](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/getting-started/installation-vite.mdx) |
| Notes appear but TAB or standard notation is missing | Confirm that the track has a suitable staff and that `display.staveProfile` includes it. Inspect staff tuning and string/fret data in the source score. | [`staveProfile`](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/reference/settings/display/staveprofile.mdx), [score data model](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/reference/score.mdx) |
| Printed layout differs from MusicXML | MusicXML carries layout details that alphaTab may not reproduce exactly, and visual notation can differ from sound semantics. Check the feature table for each relevant element and value. | [MusicXML support](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/formats/musicxml.mdx) |
| Audio does not start | Confirm the player is enabled, `playerReady` has fired, the SoundFont loaded, and the API has no error. Check the runtime SoundFont URL and that the score has playable content. | [Web player tutorial](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/tutorial-web/player.mdx), [`soundFont`](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/reference/settings/player/soundfont.mdx) |
| A loop plays the wrong occurrence | Check both the score's shared repeat sequence and the app's route occurrence index. `playbackRange` takes MIDI ticks, not bar numbers. | [Score data model](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/reference/score.mdx), [`playbackRange`](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/reference/api/playbackrange.mdx) |
| Works locally but fails after deployment | Verify the Vite `base`, font and SoundFont URLs, worker/worklet output, and service worker precache list. Test a production build served from the same subpath used by hosting. | [Vite installation](https://github.com/CoderLine/alphaTabWebsite/blob/72f8d0ccce53f2563c4fb5cf5b1560396f5b3f45/docs/getting-started/installation-vite.mdx), tutorial project's [`vite.config.ts`](../../vite.config.ts) and [`sw.js`](../../public/sw.js) |
