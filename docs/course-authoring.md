# 歌曲课程编写规范

新增歌曲时，目标是制作一份可在网站内完成学习的“拾音教学编配”：用户从第一步开始就能看见并弹奏实际的课程音符，不需要另开曲谱网页。它是本站独立编写的教学材料，不冒充或逐页复制某个商业编配；曲目来源仅作为编写核验和歌曲详情中的可选参考。

## 1. 先锁定唯一参考版本

为每首歌选定一个可访问的参考编配，并在 `Song.scoreUrl` 中保存直达链接。动手写课程前先打开并核对谱面本身，不要只依据搜索摘要、歌名或其他版本的吉他谱推断。

记录能从该版本明确确认的资料：

- 乐器与编配者；调式、变调夹/移调方式、拍号和标注速度。
- 谱面实际列出的和弦名称，以及每个和弦图是否与 `CHORDS` 指法数据一致。
- 谱面出现的伴奏型、段落名称、重复/回跳和结束位置。
- 具体小节的和弦顺序与节奏，只有在谱面清楚可读并逐项核对后才能作为课程片段使用。

如果某项看不清、参考页面打不开，或不同版本相互矛盾，就标为“待核对”并链接来源；不要猜测补全，也不要把其他版本的信息混进当前课程。

## 2. 区分和弦清单与和弦进行

`Song.chords` 表示这份参考谱中会用到的和弦清单，不表示歌曲中的时间顺序。展示时可以按谱头或和弦表的顺序排列，但不要仅凭清单顺序生成“第 1 小节、第 2 小节”。

歌曲进行必须来自谱面上可确认的连续片段。和弦转换练习若为了练手而人工配对，应写明“换位练习，不代表歌曲顺序”。不要从任务标题、描述文本或和弦清单顺序中自动推断原曲进程。

## 3. 站内教学谱与歌曲参考分开展示

- 每首课都要有完整的段落顺序和结构化小节数据，谱卡直接画在练习页，支持按段分页、试听和完整路线演奏。
- 谱卡统一标注“拾音教学编配”，不得称为某参考谱的原谱转录。课程旋律应保留可辨认主题与段落顺序；伴奏由简到繁添加。无法确认的内容不得标成已核实的原曲细节。
- 练习谱至少记录弦、品位、拍点、时值、休止/延音、同拍音、和弦与扫弦；重复段落引用同一段落数据。试听必须使用与绘图相同的音符数据。
- 每个任务明确映射到实际小节；第 1 天包含真实课程音符。降级时同时缩短谱面范围和步骤，不得只改文字。
- 完整参考来源可以放在歌曲详情作为自愿查看入口，练习页不能要求用户跳转或自己找谱。

## 4. 新增课程的建议步骤

1. 先录入歌曲基本信息、来源、路线图和已核实的和弦清单。
2. 设计八阶段学习目标：认识歌曲、单个和弦、和弦转换、节奏型、分段慢练、完整演奏、加入演唱、完整弹唱。
3. 每个阶段只给一个当天能完成的目标；写清“今天做什么、为什么、怎么做、成功标准”和一个更容易的替代练习。
4. 只有核对过的谱面内容才制作参考谱片段。其余内容按基础练习编写并清楚标注性质。
5. 和弦初学步骤须包含具体弦、品位、手指或可点开的指法图；不能只写“按 C 和弦”。节奏须解释拍数、方向和延音/空拍含义。
6. 避免要求用户自己找段落、圈小节、认重复、猜换和弦位置。若课程依赖参考谱，直接指出应看的段落或位置；没法确认时就不要编造定位。
7. 更新测试，覆盖歌曲来源、和弦数据、八阶段、可执行步骤、降级练习，以及“示意不是原谱”的文案。

## 5. 谱面与版权边界

网站只显示本站编写的教学编配，不嵌入/复制整份商业曲谱，不收录完整歌词、原唱录音或专辑封面。歌曲外部来源不是完成课程的前置条件；练习页必须能够独立完成当天学习。

## 6. 本次校准示例：《安和桥》

当前选择的参考版本是[《安和桥》G 调参考谱](https://www.ukuleleba.com/22127.html)。核对到的谱面信息为 G 调、4/4 拍、约 65 BPM，和弦清单 C、D、Em、G，并标有伴奏型 A、B。和弦清单不等于连续进行；本站的四拍均匀下扫只作为零基础拆手练习，不冒充 A/B。后续如要新增原曲小节，须先从这份参考谱逐拍核对后再录入。

## 7. 本次校准示例：《成都》

当前选择的参考版本是[《成都》参考谱](https://www.ukuleleba.com/22137.html)，并用用户提供的谱面截图复核了谱头。确认信息：C 指法、原曲 D 调、6/8 拍、约 91 BPM；和弦清单为 C、G、Em、Am、F、Dm；谱面有一种伴奏型。谱头提供女声 0 品、男声 2 品两个夹弦参考，但课程应提醒用户按个人音域决定，不把夹 2 品作为所有人的硬性要求。

该谱的伴奏型含拨弦动作，因此“第 1、4 拍下扫，其余延续”的图只能标成 6/8 入门数拍练习，不能叫原曲伴奏谱。参考谱尚未逐小节核验的内容，不得自动生成歌曲和弦顺序；每日任务应提供明确的低门槛动作与节拍说明，不让零基础用户自行圈谱、找重复或推断和弦落点。待某段小节线、和弦及节奏全部核对后，才能制作标明段落和来源的短教学谱例。

## 8. 指弹曲目编写规范

指弹课程使用 `kind: 'fingerstyle'`，八个阶段依次为：认识四线谱、右手拨弦、单音旋律、加入和声音、前段慢练、后段慢练、连接全曲、完整独奏。每一步都要写清今天拨哪根弦、左手按哪一品、使用哪根右手手指、成功标准和更容易的替代练习。

- 默认调弦为 High-G：从上到下 G、C、E、A。若参考版本使用 Low-G、变调夹或不同调弦，必须单独记录，不能继续套用 High-G 图。
- 四线 TAB 每条线代表一根弦，数字代表品位，0 代表空弦。说明左右手指法；同时拨奏要明确标出同一拍的音，避免误导成先后弹奏。
- 参考谱版本、调弦、调性、拍号、速度及段落必须逐一核验。谱面没有标注或无法确认时写“未标注/待核对”，不得猜测。节拍器练习拍号与原曲拍号应分开表达。
- 站内 TAB 只使用核实过的必要短片段，或明确写“拾音自制技巧练习，不是原曲谱”；不能把自制音型称作歌曲旋律，也不能从另一版本复制大段 TAB。
- 指弹歌曲完成条件只有“完整独奏”自我确认，不要求演唱；弹唱课程仍分别确认完整演奏和弹唱。两类都计入整体五首曲目目标。
- 新增指弹歌曲时测试八个任务、TAB 弦名与品位、离线可用、拍号显示、单曲完成规则和 v1 备份兼容。

本批课程固定参考来源：

- 《天空之城（君をのせて）》：[四线指弹参考谱](https://www.ukuleleba.com/22389.html)。按用户提供的整页谱核对后，确认标准调、4/4、约 92 BPM，谱面按 1、4、7、10、13、16、19、22 小节号分成八行、每行三小节，共 24 小节。课程按这些原谱行定位练习，不用通用自制 TAB 音型代替原曲。该谱的 TAB 从上到下是 A、E、C、G 弦；数字是品位、0 是空弦。
- 《Always with Me》： [白熊音乐简易独奏教学](https://www.ukuleleba.com/14714.html)。网站按器乐独奏教学；这首歌的作曲与演唱署名为木村弓，不要误记为久石让。原谱拍号、速度与具体练习小节须核验后才可展示。
- 《卡农（C 调改编）》： [Mr Pook C 调指弹谱](https://ukulele-pdf.com/canon-in-c-mr-pook/)。课程标题必须保留 C 调改编说明，不能与其他调的版本混为一谈。
- 《Summer（菊次郎的夏天）》： [Ukulele Hunt 指弹编配](https://ukulelehunt.com/2022/05/05/joe-hisaishi-summer-from-kikujiro-tabs/)。若教学涉及掌根闷音、琶音或特殊调弦，先核对谱面具体标记；初学练习需分动作引入。

这些链接仅作为内部核对参考和详情页的可选来源。本课程站内音符采用统一的 High-G 拾音教学编配；拍号与速度属于教学设置，界面应清楚标注，不得把参考版本的编配者姓名作为课程品牌或主要展示内容。

## 9. 站内谱卡交付检查

- 七首曲目每首都要有从开头到结尾的演奏顺序；重复段落以引用复用，不复制一份新谱。
- 八个课程任务全部绑定有效小节；降级范围少于正常范围；完整独奏/弹唱任务覆盖全曲顺序。
- 统一四线谱从上到下为 A、E、C、G；说明 0 为空弦、品位数字、同时拨奏、延音与扫弦箭头。
- 检查拍点边界不溢出小节；6/8 的四分附点 BPM 每小节两次主拍（第 1 与第 4 个八分位置），节拍器、谱面和试听时长一致。
- 手机每页优先显示 1 小节，桌面最多 2 小节；不横向滚动；分页按钮至少 44px，有读屏播报和键盘焦点。
- PWA 更新缓存版本；单测覆盖 7 份谱、56 个任务映射、重复顺序、音符/和弦有效性和降级范围。
