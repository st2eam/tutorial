# 技能课程编写规范

## 通用步骤课程

新技能课程放在 `src/data/guided-courses/<course-id>.ts`，以默认导出一个 `GuidedCourse`。目录会由课程目录自动发现，不需要修改页面组件。

```ts
import type { GuidedCourse } from '../catalog'

const course: GuidedCourse = {
  type: 'guided',
  id: 'example-skill-basics',
  category: { id: 'craft', title: '手作', description: '用双手完成一件作品。' },
  skill: { id: 'example-skill', categoryId: 'craft', title: '示例技能', description: '从基础动作开始。' },
  title: '入门练习',
  description: '完成几个短步骤，建立基础。',
  lessons: [{
    id: 'example-skill-basics-01',
    title: '认识工具',
    why: '先熟悉工具，后续练习会更顺手。',
    steps: ['准备所需工具。', '逐一确认工具用途。'],
    success: '能说出每件工具的用途。',
    simplifiedSteps: ['先找出最常用的一件工具。'],
    simplifiedSuccess: '能找到并拿起这件工具。',
  }],
}

export default course
```

每门课程至少包含一个步骤。每步要有明确目标、可执行动作、成功标准和更简单的替代练习。分类 ID、技能 ID 和课程 ID 应稳定且唯一；共享同一技能的课程需使用相同的分类与技能信息。课程内容作为静态文件发布，进度按课程和步骤 ID 保存。

## 歌曲课程：数字谱文件优先

七首歌曲统一以标准数字谱文件作为显示和演奏的音符来源。当前采用 MusicXML 4.0，使用 alphaTab 在页面绘制和播放；四弦 TAB 默认显示，并可切换为同时显示五线谱。教学文字继续负责目标、动作、成功标准和降级练习。

每首歌维护两部分静态数据：

- `public/scores/<song-id>.musicxml`：一份完整课程谱，包含调弦、拍号、速度、五线谱、TAB 弦号与品位、时值、休止、延音、声部、和弦/扫弦标记及重复小节线。
- `src/data/score-manifest.ts`：唯一参考链接和署名、核对状态、段落到小节映射、实际演奏顺序。演奏路线重复引用同一段落时，使用 MusicXML 重复记号和 `playOrder` 引用，不复制另一份段落数据。

第三方 GP、MusicXML 或其他数字谱只有在版本、四弦指法、演奏顺序和公开再发布许可都已核实后才可收录；记录原始文件版本及授权页面。网页能打开或用户能下载不等于可再发布。没有合格文件时，将本站原创教学编配保存为 MusicXML，并清楚写“拾艺教学编配／旋律待核对”。不得从和弦清单或另一版本推断歌曲旋律。用户提供并明确要求用于个人课程的谱面，以该文件为唯一录入和署名来源；不得把截图或裁图打包进网站。

alphaTab 与离线资源要求：

- 引入来源明确的 alphaTab 版本，并遵循其授权；TAB 与五线谱共享同一 MusicXML 音符数据。
- 播放、显示光标、速度控制、按小节循环和自动跟谱必须使用同一谱文件。移动端每页 1 小节、桌面最多 2 小节；播放自动翻页不能打断声音。用户手动翻页、切歌或离开课程时停止并清理播放器。
- 只使用明确允许再发布的音色文件。当前尤克里里音色为 FreePats CC0，授权文本随文件保存在 `public/soundfonts/`。
- 更新服务工作线程缓存版本，并离线预缓存课程谱、音色、字体和播放器 worker/代码资源。

## 歌曲八阶段与映射

课程编写顺序固定为：先将完整曲目谱放在曲目详情页，用指定参考版本核对全曲音符、节奏与演奏顺序；核对记录完成后，再按同一份 MusicXML 编写八阶段任务。谱面存在未能辨认的内容时，相关结论保留“待核对”，课程不得把它写成已核实的原曲细节。

保留已有课程 ID 和任务 ID。每首歌曲八个任务都必须绑定具体段落及小节；任务 1 就能看到并弹奏课程音符。降级练习必须映射到更短的小节范围，也要缩短文字步骤。

指弹课阶段为：认识四线谱、右手拨弦、单音旋律、加入和声音、前段慢练、后段慢练、连接全曲、完整独奏。弹唱课阶段为：认识歌曲、单个和弦、和弦转换、节奏型、分段慢练、完整演奏、加入演唱、完整弹唱。每一步说清拨哪根弦、按哪一品、右手手指、节拍/时值和成功标准；弹唱还要说明和弦及扫弦方向。

## 核对与交付

开始编写前锁定唯一参考版本；记录页面或数字文件的固定版本、访问日期、编配者、调弦、调式、拍号、标注速度、和弦清单、段落与许可。具体旋律及节奏只有在可读并逐项核对后才能写成“已核实”；其余标为“待核对”，不得混入其他版本。和弦清单表示曲中出现过的和弦，不代表时间顺序。

交付前至少检查：

- 七份 MusicXML 均可由 alphaTab 解析；四条弦的调弦、弦号和品位有效，休止、延音、同拍音和小节时值边界正确。
- 七首完整演奏路线顺序有效；56 个任务都有正常范围和更短的简化范围，重复段落共用相同小节数据。
- TAB 与五线谱可切换；试听使用同一文件，6/8 附点四分音符速度的谱面时长与播放一致。
- 手机和桌面分页、焦点、屏幕阅读器页码与横向溢出行为正确；试听可停止，自动翻页后播放继续。
- PWA 离线缓存含曲谱、音色和运行所需播放器资源；进度备份和稳定任务 ID 兼容。
- 更新来源核对记录、播放器/谱文件测试和缓存版本，再运行现有测试与构建。

## 本批歌曲来源策略

截至 2026-09-24，当前指定来源中未找到同时满足版本可核实、四弦尤克里里格式可解析、且允许公开再发布的第三方数字谱。因此六首歌曲使用拾艺自制 MusicXML 教学音型，旋律逐音对应标为待核对。天空之城使用用户提供的参考谱截图作为录入核对材料，MusicXML 保留编配署名和来源链接；不将图片作为站点资源。逐首来源、状态与结论见 `docs/song-source-audit.md`。
